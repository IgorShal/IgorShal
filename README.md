### 🧭 [SLAM Indoor](https://github.com/FIT-2023-SLAM-indoor/slam-indoor-code)

The most technically complex university project I worked on: indoor 3D reconstruction / SLAM system for building a point cloud from images.

**What the project does:**

- Processes image sequences
- Estimates camera movement
- Builds a 3D point cloud of indoor space
- Uses classical computer vision algorithms and optimization

**My contribution:**

- Worked on C++ computer vision pipeline
- Used **OpenCV** for image processing and geometry
- Participated in performance-related improvements
- Helped integrate **CUDA** support for acceleration
- Worked with CMake-based native build system

**Stack:** C++, OpenCV, CUDA, CMake, Ceres Solver
